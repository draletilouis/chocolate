# Cocoa Production System

Separate chocolate factory production project using the visual language and interaction patterns from the previous UI reference app.

## Run locally

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:3100`.

The current build is an interactive screen prototype with sample data. It demonstrates the production flow, mass balance, inventory and traceability screens, formulations, reports, configuration, and responsive layouts. Data resets when the page refreshes.
